# Awan Tax Law Associates

Responsive static website for income tax return filing services in Pakistan.

## Publish with GitHub Pages

In repository Settings → Pages, select Deploy from a branch, choose main and / (root), and Save.

Expected address after Pages is enabled: https://sajjadicap786-hue.github.io/Awan-Tax-Law-Associates/

## Business details

WhatsApp / phone: +92 333 5232992

Office No. 216, Saleem Heights, Satellite Town, Rawalpindi, Pakistan.

Add a confirmed business email to BUSINESS.email in script.js. Replace the Facebook search link in index.html with the exact official page URL when available.

The enquiry form prepares a message locally without storing or submitting information. Users copy the message and send it to the business. The WhatsApp button opens the confirmed business number.

## Preview locally

Run python3 -m http.server 8080 in this directory and open http://localhost:8080.
